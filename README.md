## 新玩家怎么安装

### macOS

1. 下载上方 macOS zip 并解压，得到 `未来中学日语物语.app`
2. 将 `.app` 拖到 `/Applications` 或 `~/Applications`
3. 打开 App。若被拦截：系统设置 → 隐私与安全性 → 仍要打开

### Windows

1. 下载上方 Windows zip，解压整个文件夹（不要只抽出 exe）
2. 双击 `KyoanJapanese.exe`（也可双击 `start.bat` 或 `启动.bat`）
3. 若 SmartScreen 提示「已保护你的电脑」，点「更多信息」→「仍要运行」
4. 不需要安装 Python、Node 或 Chrome

详细步骤见 [INSTALL.md](./INSTALL.md)。

## 软件内检查更新

1. 打开游戏菜单 → **更新情報**（或访问 `update.html`）
2. 点击 **检查 GitHub 更新**
3. 若有新版本且已上传安装包，按提示打开对应平台的下载链接；解压后覆盖本地目录、`.app` 或 Windows 解压文件夹，再重启

本地也可点「更新を確認」查看同目录 `update.json` 的更新说明；「キャッシュ更新」用于刷新浏览器缓存。
