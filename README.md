## 新玩家怎么安装

1. 打开上方 Release 页或直接下载 zip
2. 解压得到 `未来中学日语物语.app`
3. 将 `.app` 拖到 `/Applications` 或 `~/Applications`
4. 打开 App。若被拦截：系统设置 → 隐私与安全性 → 仍要打开

详细步骤见 [INSTALL.md](./INSTALL.md)。

## 软件内检查更新

1. 打开游戏菜单 → **更新情報**（或访问 `update.html`）
2. 点击 **检查 GitHub 更新**
3. 若有新版本且已上传安装包，按提示打开下载链接；解压后覆盖本地目录或 `Applications` 中的 `.app`，再重启

本地也可点「更新を確認」查看同目录 `update.json` 的更新说明；「キャッシュ更新」用于刷新浏览器缓存。
